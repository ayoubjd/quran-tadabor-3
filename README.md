# Quran Reader PWA

A Progressive Web Application (PWA) for reading the Quran, complete with Surah bookmarks, reader settings, and offline capabilities.

## Structure

- `/quran-reader`: Contains the main application source code (HTML, CSS, JS).
- `/quran-pages`: Contains the image files for the Quran pages.
- `/books`: Additional books and resources.

## Deployment

This application is configured to be deployed on Vercel with the **Root Directory** set to `quran-reader`.
